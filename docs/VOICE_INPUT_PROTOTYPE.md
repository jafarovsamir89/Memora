# Тестовый голосовой ввод на Android

**Область:** частичная работа MEM-13.01/13.03/13.04, не готовый AI-помощник. Владелец разрешил в будущем облачный AI с отдельным подтверждением передачи данных; конкретный провайдер, маршрут и передача ещё не определены. Цены не исследуются. [ADR-007](adr/ADR-007-ai-routing.md) · [безопасность](SECURITY_AND_PRIVACY.md).

## Контракт

С Android 12/API 31 приложение выбирает только предоставляемый системой `createOnDeviceSpeechRecognizer`, если он доступен. Это выбор API устройства, а не самостоятельный аудит установленного системного сервиса. Наличие модели, языков RU/AZ/EN и качество необходимо проверять отдельно; отсутствие локального сервиса, языка, модели или разрешения приводит к понятному состоянию и сохранению текстового пути. На API ниже 31 голосовой путь недоступен. Автоматического перехода к облачной службе нет.

Микрофон запрашивается только после явного нажатия пользователем; показаны состояния ожидания, прослушивания, обработки, отказа и ошибки. У пользователя есть остановка и отмена. При закрытии панели, уходе приложения в фон или разрушении интерфейса сессия отменяется, обработчик освобождается, поздний ответ отменённой сессии игнорируется. Приложение не сохраняет аудиофайл и не записывает речь в диагностику.

Распознанный текст помещается только в редактируемый черновик; существующий текст не стирается, и результат свыше лимита не обрезается незаметно. Экспериментальный текстовый черновик теперь сохраняется локально автоматически, а явное действие создаёт локальный источник без AI-действий. Для тестовых источников добавлены ограниченные экспорт и удаление; по-прежнему допускаются только вымышленные данные. Этот локальный ввод остаётся отдельным от экспериментального облачного диалога и системной озвучки ответа. Для личных данных и настоящего качества нужны проверка устройства и политика жизненного цикла данных.

| ID | Сценарий и ожидаемый результат |
| --- | --- |
| V01 | До нажатия и разрешения микрофон не запускается. |
| V02 | Локальный сервис отсутствует: отказ с текстовой альтернативой, сетевой fallback не вызывается. |
| V03 | Отмена или закрытие: обработчик освобождён, поздний результат не меняет черновик. |
| V04 | Результат: текст доступен для редактирования, не отправлен и не сохранён автоматически. |
| V05 | Переполнение, пустой результат или ошибка: текущий черновик не уничтожается; видна ошибка. |
| V06 | Уход в фон: захват останавливается. Настоящая проверка микрофона и локальных RU/AZ/EN-моделей на устройстве остаётся открытой. |

Указанные случаи должны быть проверены на тестовой реализации и, отдельно, на телефоне; автоматические моки не являются приёмкой распознавания.
