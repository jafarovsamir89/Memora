# Контракт первого программного компонента списка дел

**Дата:** 2026-10-30. Частичный результат MEM-01.10/01.12 и подготовка MEM-11.01. Этот контракт относится только к чистым правилам задачи, без UI, базы, персональных данных, AI и сети. Он не закрывает ни одну из этих задач целиком. [ADR-001](adr/ADR-001-native-architecture.md) · [ADR-008](adr/ADR-008-ai-actions.md).

## Область

Вход — явно инициированное пользователем создание задачи или изменение её названия/отметки выполнения. Название после удаления крайних пробелов не пустое и содержит не более 200 Unicode-кодов; внутренний текст сохраняется. Для создания нужны непустые стабильные ID задачи, области, автора и команды; никакой генерации ID или времени внутри домена. Новая задача активна, версия 1. Две задачи с одинаковым названием и разными ID различны.

Изменение указывает ожидаемую версию; устаревшая версия возвращает конфликт и не создаёт событие. Идентичное название или состояние возвращает отсутствие изменения без нового события и увеличения версии. Допустимое изменение создаёт событие с идентификаторами задачи, области, автора и команды, старой и новой версиями. Применение события проверяет соответствие ID, области и версии; неправильное событие не меняет состояние. Существование автора и право на действие проверяет вызывающий слой; этот компонент не является авторизацией. Он не хранит журналы или тексты и не обрабатывает удаление.

Повтор команд, атомарная запись события, восстановление после сбоя, журнал и безопасность хранения являются обязанностью отдельного слоя хранения. В частности, этот чистый компонент **не обеспечивает идемпотентность повторной доставки** и не допускается к обработке реальных данных без остальных контрактов и проверок. Для тестового пути добавлены явный срок с поясом, подписи человека/проекта и флаг напоминания; это не связи с полноценными сущностями. Приоритет, вложения, поиск и многопользовательские права ещё не реализованы.

## Приёмочная карта — синтетические тесты

| ID | Проверяемый случай | Ожидаемый результат |
| --- | --- | --- |
| T01 | Создание с названием и явными ID | Активная задача версии 1; сохранены область, автор и ID команды. |
| T02 | Пустое название, пустые ID или название длиннее 200 кодов | Ошибка валидации, событие не создаётся. |
| T03 | Смена названия и отметки | Получается новое событие; применение последовательно увеличивает версию и не меняет предыдущий объект. |
| T04 | Устаревшая версия или событие другой задачи/области | Конфликт; данные остаются прежними. Это локальная часть S26/S29, не проверка сервера. |
| T05 | Повтор установки уже выбранного значения | Нет нового события или версии. Это не проверка идемпотентности доставки S30. |
| T06 | Одинаковое название у двух задач с разными ID | Разные задачи остаются различными. |
| T07 | Указать срок и пояс | Сохраняются локальные дата/время и ID пояса; несуществующее или неоднозначное местное время отклоняется. |
| T08 | Указать человека и проект | Сохраняются введённые подписи; они не объявляются разрешёнными ссылками на реальные сущности. |
| T09 | Напоминание без срока | Изменение отклоняется; срок в прошлом не объявляется доставленным напоминанием. |

Автотесты используют только синтетические данные. До использования в приложении нужны отдельные проверенные хранение, права, удаление, восстановление, UI и реальное устройство; результаты JVM-тестов их не заменяют.
