# Эксперимент облачного голосового диалога — контракт

**Статус 2026-10-31:** владелец поручил повседневное использование локальной памяти и установил AZ главным языком, с RU/EN и смешанной RU/AZ речью. Это не production-приёмка. Инженерные внешние API-тесты используют только синтетические данные и пока только Gemini. Отправка пользовательского аудио требует отдельного согласия; архив и инструменты автоматически не подключены. [Решение и сравнение](AZERBAIJANI_VOICE_PLAN.md).

## Маршрут и согласие

Сессия Firebase AI Logic → Gemini Developer API `gemini-3.1-flash-live-preview` по App Check. Без общего Gemini API-ключа в приложении. Перед первым использованием режима пользователь видит, что аудио непрерывно передаётся Google, Google на бесплатном уровне может использовать данные для улучшения сервисов, а системный микрофон остаётся активным до остановки. Согласие запоминается на устройстве и отзывается в настройках. Отказ закрывает диалог без микрофона и сети. Системное разрешение микрофона не заменяет согласие на Google. Текстовые настройки/история задач/архив памяти не передаются, инструменты не включаются.

После согласия и разрешения микрофона — явные состояния подключения и активной записи, кнопка остановки. Остановить захват, воспроизведение и соединение при остановке, уходе в фон, закрытии экрана, отмене или ошибке; позднее подключение после отмены не должно включить микрофон. Сессия ограничена одной минутой как начальное защитное ограничение, не как обещание квоты. При сбое не объявлять успешное распознавание; повтор — новый явный запуск с новым согласием.

## Языки и проверка

Инструкция AZ-first едина для Live и текстового Gemini: не подменять язык турецким, сохранять имена, суммы, отрицания и смешанные фразы, уточнять неразборчивое и не обещать неподтверждённые действия. Голос `Kore`, VAD LOW/LOW, prefix 50 мс и пауза 800 мс — инженерные начальные настройки, а не доказанный оптимум. SDK-рекордер использует VOICE_COMMUNICATION. Язык Live задаётся инструкцией: явный languageCode не поддерживается. Текстовые потоки пользователя и модели разделены; переполнение 20000 символов останавливает сессию вместо потери начала. После остановки только текст пользователя можно отправить на локальный просмотр; непустой текущий черновик не затирается.

## Законченная голосовая заметка

**Обновление ACT-0218:** владелец получил `stt_failed` на основной кнопке удержания. Предыдущая реализация отправляла `gemini-3.5-transcribe-live` сырым WebSocket через Firebase AI Logic proxy. Модель существует в Gemini/Agent Platform, но отсутствует в актуальном списке моделей, поддерживаемых именно Firebase AI Logic; Google указывает, что Firebase AI Logic поддерживает только модели из своего списка. Причина конкретного HTTP сбоя не была раскрыта кодом приложения, поэтому несовместимость маршрута — установленная ошибка интеграции и вероятная причина, но не доказанный статус того запроса.

Новый маршрут «Расскажи»: отдельное согласие → микрофон → до 25 секунд mono PCM16/16 kHz WAV в RAM → Firebase AI Logic Android SDK `generateContent` с поддерживаемым `gemini-3.8-flash` и inline `audio/wav` → Gemini agent → облачная речь. SDK сам применяет Firebase App Check; собственного WebSocket/proxy-протокола для этой законченной записи больше нет. Модель получает verbatim-инструкцию AZ-first с поддержкой RU/mixed; без неподтверждённой информации, переводов и автоматических действий. Согласие охватывает запись и последующую обработку Google; архив не передаётся. Качество языка и реальное устройство должны быть повторно приняты владельцем; текущая замена транспорта сама по себе не закрывает MEM-13.08/13.09.

После STT текстовая проверка письменности по-прежнему использует `gemini-3.1-flash-lite` только для возможного перехода русских слов в кириллицу; при сбое остаётся исходная расшифровка с локальной орфографической подсказкой, доступен просмотр оригинала. Для текста без латиницы дополнительного запроса нет. Числа, отрицания, порядок токенов и пунктуация защищены; пользователь проверяет имена и суммы. Никакой сырой звук или текст исключения не попадает в логи. Ошибка на главном пути теперь показывает безопасный код этапа: `audio_*`, `stt_*` или `assistant_*`; это диагностическая подсказка, а не основание автоматически повторять отправку.

При отказе текстовой стадии сохраняется исходный STT с единственной локальной орфографической подсказкой `değil`→`deyil`; исходник доступен без изменений. Эта замена не применяется внутри других слов. Аудиофайл не создаётся; возвращённый WAV очищается после STT/отмены, временные PCM-буферы освобождаются. Полное гарантированное обнуление всех копий управляемой памяти не заявляется. Отмена/фон прекращают запись и не применяют поздний результат, включая текстовую стадию. Полученный текст не заменяет существующий черновик, а добавляется после проверки. Локальный системный ввод остаётся альтернативой в отдельном режиме. Запуск заметки из разговора заблокирован, пока Live активен; диалог остаётся отдельной кнопкой, его точность/произношение требуют приёмки владельца.

Google перечисляет азербайджанский, русский и английский среди языков Live API; это не свидетельство качества на конкретном устройстве. Модель получает инструкцию отвечать на языке пользователя, включая смешанную RU/AZ речь. Нужны синтетические фразы с именами, числами, отрицанием, долгами и переключением языков; сравнить реальную аудиозапись и ответ, а также отмену/отказ/сеть и выход в фон на Redmi. Не делать вывод о точности по одному примеру. Если модель или бесплатная квота недоступны аккаунту — показать ошибку, не включать биллинг и не обходить App Check.

Ограничения: Live API через Firebase — preview; источник https://firebase.google.com/docs/ai-logic/live-api. Языки https://ai.google.dev/gemini-api/docs/live-api/capabilities. Модель и бесплатная доступность https://firebase.google.com/docs/ai-logic/models. Правила обработки: https://ai.google.dev/gemini-api/terms.


## App Check debug token для тестового Android

Firebase AI Logic автоматически требует App Check для запросов с 2026-11-02. Для debug APK нельзя рассчитывать на новый SDK debug token, пока он не зарегистрирован для Firebase-приложения. На телефоне следует проверять сохранённый debug token обменом `exchangeDebugToken` и статусом Settings → Firebase App Check test access → Save and verify. Только после статуса принятия выполнять синтетический речевой тест. Токен остаётся локальным секретом: не отправлять его в чат, не коммитить, удалить из Console после окончания тестирования. ACT-0220 зафиксировал HTTP 403 для текущего токена; голосовая приёмка остаётся открытой.
