# Напоминания для тестовых задач

Данный пакет — частичное выполнение MEM-11.05–11.08. Срок можно задать явной местной датой/временем или точным относительным интервалом `remind_in_minutes`; приложение вычисляет относительный срок от часов устройства в указанном IANA-поясе (по умолчанию `Asia/Baku`). Относительный интервал должен быть целым числом от 1 минуты до 365 дней; одновременно абсолютный и относительный срок отклоняются. Неоднозначное и несуществующее местное время отклоняется. Подписи человека и проекта являются произвольным текстом, а не ссылками на реализованные сущности.

Напоминание включается пользователем явно; если разрешение Android на уведомления отсутствует, задача сохраняется, но напоминание возвращает статус `denied`. Используется неточное системное расписание: доставка может задерживаться, её нельзя считать гарантированной или прочитанной. Уведомление показывает название задачи в приватном тексте; система может скрыть его на заблокированном экране. При срабатывании состояние заново сверяется с локальными данными. Выполнение, удаление или изменение срока отменяет прежнее расписание. При открытии раздела дел и системном запуске после перезагрузки будущие напоминания пересоздаются; просроченные не рассылаются пачкой. Закрытое приложение, перезагрузка, системные ограничения и Android 13 требуют испытания на реальном телефоне; локальные тесты не заменяют их.

Проверка доступности учитывает системное разрешение, общий запрет уведомлений приложения и отключение существующего канала напоминаний. Если канал ещё не создан, его наличие не требуется. Настройки показывают состояние и открывают Android: после изменения пользователь возвращается в приложение и открывает «Дела» для перепланирования будущих напоминаний. Открытие системных настроек само по себе не означает, что доступ изменился; состояние считывается заново при возвращении. Разрешение не гарантирует звук или доставку: например, влияют режимы устройства и ограничения системы.

| ID | Сценарий | Ожидание |
| --- | --- | --- |
| R01 | Будущий срок и разрешённое напоминание | Создано одно неточное системное задание. |
| R02 | Задача выполнена, удалена или срок изменён | Старое задание отменено; устаревшее срабатывание не должно показать уведомление. |
| R03 | Срок уже прошёл или разрешение отсутствует | Нет заявления о доставке; при отсутствии разрешения пользователь видит ограничение. |
| R04 | DST-переход | Неоднозначное или несуществующее время не сохраняется. |
| R05 | Перезапуск приложения / системная перезагрузка | Будущие задания восстанавливаются из сохранённых задач; на устройстве сценарий ещё необходимо подтвердить. |
| R06 | Пользователь задаёт «через N минут» | Инструмент передаёт целое число минут; приложение рассчитывает срок от своего текущего времени, сохраняет задачу и планирует локальное уведомление. Проверены вычисления для `Asia/Baku`, перехода через полночь, неверной зоны и неоднозначного DST-времени. |
| R07 | Срабатывает задача с названием | Уведомление содержит сохранённое название задачи; фактическую доставку на устройстве и влияние режима энергосбережения ещё нужно подтвердить владельцу. |
