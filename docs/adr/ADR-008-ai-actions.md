# ADR-008: разрешения инструментов и подтверждение действий

**Статус:** инженерное решение для проектирования, 2026-10-30; MEM-01.08. [Сценарии](../SCENARIOS.md) · [ADR-002](ADR-002-memory-provenance.md) · [ADR-005](ADR-005-commands-and-sync.md). Реализация отсутствует.

## Решение

Модель может предложить действие в структурированном виде, но полномочия проверяет приложение независимо от модели и текста источника. Инструмент допускается только по явному списку с типизированными аргументами, конкретной областью, субъектом, целью и разрешением на операцию. Модель не получает произвольный доступ к файловой системе, секретам или другим пространствам. Исходный документ, уведомление и ответ инструмента не могут расширять полномочия.

Начальная матрица риска для разработки: чтение разрешённой области допускается только в рамках явно инициированного пользователем запроса; сохранение или изменение памяти, денег и задач требует подтверждения точного содержания; внешняя отправка, платёж, публикация, приглашение и удаление требуют отдельного явного подтверждения последствий. Доступность конкретного инструмента всё равно определяется разрешениями и зрелостью реализации. Автоматическое низкорисковое сохранение пока отключено и может появиться только после отдельного контракта, тестирования и понятной настройки пользователя.

Подтверждение связывается с устойчивым ID, версией и содержимым действия, областью, адресатом, суммой/валютой, источником, зависимостями и существенными последствиями. Перед применением повторно проверяются права, версия, неизменность содержания и необходимые предпосылки. При изменении значимого поля требуется новое подтверждение. Подтверждение одной операции не разрешает другую; отказ или отмена до начала исполнения запрещает её применение. Для уже выполненных внутренних изменений возможна только определённая доменом компенсация; отправленное внешнее действие не обещается отменить без подтверждения внешней системы.

Составной запрос показывает независимые действия и зависимые атомарные группы. Неоднозначная часть ожидает уточнения и не блокирует независимую часть при разрешённости её выполнения; UI показывает каждый исход. Удаление и внешние действия не запускаются из подменённых инструкций или одного факта распознавания.

## Альтернативы и будущие проверки

Универсальное доверие уверенности модели отклонено; одобрение только названия инструмента без его аргументов отклонено; автоматическое повторение внешнего действия с неизвестным исходом отклонено.

| Сценарий | Будущее ожидаемое поведение |
| --- | --- |
| S28/S29 | Подтверждённая версия не применяется после изменения суммы; независимые действия имеют отдельные статусы. |
| S35 | Отзыв права до исполнения блокирует действие даже при ранее полученном подтверждении. |
| S37 | Подмена суммы или адресата текстом источника не изменяет подтверждённую команду. |
| Отмена | До исполнения команда не применяется; после внешней отправки исход выясняется, а не объявляется отменённым. |

Перечень инструментов, окончательная матрица прав и отдельные UX-сценарии остаются в MEM-01.10–01.13; эта таблица не является результатом тестов.
