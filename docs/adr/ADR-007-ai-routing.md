# ADR-007: AI-маршруты, схемы и качество

**Уточнение 2026-10-31:** владелец установил AZ основным языком и попросил сравнить точность, задержки и стоимость Gemini Transcribe, Scribe и Groq, затем уточнил «пока тестируем только Gemini». Принято дополнение [AZERBAIJANI_VOICE_PLAN.md](../AZERBAIJANI_VOICE_PLAN.md): Firebase/App Check без общего секрета в APK, явное согласие, аудиозаметка → проверяемый текст → локальное подтверждение. Архив и инструменты не передаются автоматически. Прежние формулировки «провайдер не выбран/интеграции нет» ниже относятся к целевой многопровайдерной системе. Ценовое сравнение разрешено в пределах голосовой задачи, платные подключения не разрешены.

**Уточнение 2026-10-30:** владелец поручил тестовое подключение Google. В нативном прототипе используется Firebase AI Logic → Gemini Developer API с App Check и подтверждением каждого текста; Gemini API key не встраивается в APK. Синтетический текстовый запрос на Redmi получил ответ. Это выбор для эксперимента, а не допуск личных данных или утверждение production-маршрута. Актуальные ограничения — [VOICE_ASSISTANT_NEXT.md](../VOICE_ASSISTANT_NEXT.md).

**Статус:** инженерное решение для проектирования, 2026-10-30; MEM-01.07. [AI и голос](../AI_AND_VOICE.md) · [безопасность](../SECURITY_AND_PRIVACY.md). Провайдер не выбран; интеграции нет.

## Решение

AI — сменный адаптер, предлагающий интерпретации, а не источник истины и не исполнитель операций. Вход и выход имеют версионированные схемы, ID исходной версии, язык, тип задачи, разрешённую область данных и версию модели/настроек, если она доступна. Проверка схемы, допустимых полей, связей с источником и актуальности версии обязательна до создания предложения. Некорректный, неполный или устаревший ответ отклоняется или направляется на уточнение; свободный текст не становится командой автоматически.

До передачи пользователю объясняются маршрут, категория данных и ограничения; передача разрешается только после применимого согласия и проверки доступа. Данные минимизируются по цели, защищённые связанные объекты не включаются автоматически. Содержимое источников — данные, а не инструкции провайдеру; инструменты и адресаты задаются приложением по ADR-008. Нельзя размещать общий секрет провайдера в распространяемом APK. Без утверждённого безопасного маршрута внешняя обработка личных данных не запускается; локальная модель также выбирается и проверяется отдельно.

Уточнение владельца от 2026-10-30: облачный AI можно подключить позднее с отдельным подтверждением передачи данных. Выбор конкретного маршрута и поставщика остаётся открытым; это решение не является согласием на произвольную передачу данных или расходы.

Офлайн или отказ провайдера не превращаются в успешную обработку: разрешённый локальный захват может ожидать обработки с понятным статусом, если это допускают retention и защита. Повторы ограничиваются по числу/времени согласно будущему контракту, с возможностью отмены; точные лимиты определяются по испытаниям, и каждый ответ проверяется на актуальность. Смена модели не должна молча переписывать подтверждённые факты; новый разбор создаёт отдельную версию предложения. Детерминированные финансовые расчёты выполняются доменом.

## Оценка и альтернативы

Качество оценивается на разрешённом размеченном корпусе RU/AZ/EN и смешанной речи, отдельно по критическим суммам, именам, отрицаниям и направлениям долга; настройка и контрольный набор разделены. Объём, пороги и измерение неопределённости задаются до испытаний; confidence модели не заменяет контроль. Ценовые вопросы отложены владельцем и здесь не исследуются.

Прямое изменение базы ответом модели, общий ключ в APK и отправка всего архива ради одного вопроса отклонены. Конкретный провайдер, переносимость форматов, маршруты, регион обработки и способы авторизации не выбраны.

| Сценарий | Будущее ожидаемое поведение |
| --- | --- |
| S12/S27 | Некорректный или устаревший результат не меняет данные и возвращает понятный статус. |
| S18/S37 | Инструкция внутри документа не получает прав вызвать инструмент или подменить источник/сумму. |
| Офлайн | При недоступном маршруте приложение не выдаёт вымышленный AI-результат; разрешённый захват ожидает обработки. |
| Доступ | Отзыв прав до выдачи результата исключает закрытые данные; передача не происходит без применимого согласия. |

Это будущие проверки, не результаты тестов.
