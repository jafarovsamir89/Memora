# Голосовой AI-помощник: следующий этап

Владелец поручил подключить Google AI; приложение зарегистрировано в Firebase, Gemini Developer API и App Check включены. Добавлена экспериментальная интеграция Firebase AI Logic с отдельным подтверждением каждого текста. Входящий голос по-прежнему распознаётся системным on-device API и создаёт редактируемый текст. [ADR-007](adr/ADR-007-ai-routing.md) · [ADR-008](adr/ADR-008-ai-actions.md).

**Текущий статус:** тестовый экран и маршрут созданы. На подключённом Redmi запрос с вымышленным текстом после подтверждения получил ответ от `gemini-3.1-flash-lite` через Firebase AI Logic и App Check. Две проверенные модели семейства 2.5 вернули `ServerException`; причина не подтверждена. Это одна успешная проверка текстового запроса, не приёмка полноценного AI-помощника. Добавлена явная озвучка ответа системным TTS; её работа и языки устройства требуют отдельного испытания. Память, задачи и инструменты к ответу модели не подключены. Детали — в [дневнике](AGENT_DIARY.md) и [логе действий](ACTION_LOG.md).

**Дополнение по поручению владельца:** в экран разговора добавлен отдельный эксперимент Gemini Live API (`gemini-3.1-flash-live-preview`): аудио с микрофона передаётся Google после согласия, ответ приходит в виде облачного аудио. Модель получает инструкцию поддерживать AZ/RU/EN и смешанную речь. Состояние фактической проверки телефона и языка фиксируется в дневнике; наличие кода не подтверждает качество речи. Поток прекращается при остановке, уходе в фон или по ограничению одной минуты. Подробности — [CLOUD_VOICE_TEST_CONTRACT.md](CLOUD_VOICE_TEST_CONTRACT.md).

## Предполагаемый путь

1. Пользователь начинает запись; приложение показывает процесс и позволяет отменить. При отсутствии локальной языковой модели остаётся текстовый ввод.
2. Распознанный текст показывается пользователю для исправления. Перед отправкой во внешний AI приложение называет получателя и показывает, какие данные и для какой цели будут переданы; данные передаются только после отдельного согласия. Согласие на микрофон не является согласием на облачную обработку.
3. AI возвращает текст ответа и, при необходимости, структурированные предложения действий. Проверка контракта и прав выполняется приложением; запись, напоминание или иное действие применяются только по правилам и подтверждению соответствующей версии. История или личные факты не придумываются.
4. Ответ можно прочитать; озвучка — отдельная функция с явным запуском и остановкой. При отсутствии сети, модели, нужного языка или разрешения показывается понятное состояние без выдуманного результата.

## До подключения

- Выбрать провайдера и безопасный способ авторизации на нативном этапе без общего секрета в APK; без выбранного маршрута личные данные не отправляются.
- Документировать назначение, состав передаваемых данных, хранение и удаление у провайдера, возможности отзыва и поведение при отказе. Предусмотреть переносимость адаптера и проверку прав.
- Определить ограниченный набор инструментов, схему ответов и подтверждения, обработку сетевых ошибок и результатов неизвестного состояния. Не дать содержимому источников расширять права AI.
- Отдельно проверить запись, согласие, локальное и облачное распознавание, ошибки, отмену, источник и RU/AZ/EN на синтетическом корпусе и реальном устройстве. Различать испытания на JVM и телефоне.

Текущий запрос передаёт Google только показанный текст после отдельного согласия; задачи и память автоматически не передаются, инструменты не вызываются. Бесплатный режим Gemini допускает использование Google содержимого запросов для улучшения продуктов: использовать только вымышленные данные. Общий секрет Gemini не встраивается в APK; файл `google-services.json` сохранён локально и исключён из Git, тестовый App Check токен зарегистрирован отдельно и в Git не сохраняется. Режим Play Integrity для релиза требует отдельной настройки и проверки; отладочный токен не является production-защитой.

Для текстовых ответов кнопки озвучивания и остановки используют системный движок телефона; он может использовать сеть, о чём предупреждает интерфейс. Новый облачный голосовой диалог использует непосредственно аудио Gemini, отдельно от системного TTS. Доступность и приватность конкретного системного TTS-провайдера не подтверждены. Испытания озвучки и голосовых языковых моделей на телефоне, надёжная оценка ответов и допуск личных данных ещё не завершены. Собственный backend строится только после MEM-14.09.
