# Азербайджанский голос и личная память

Решение владельца от 2026-10-31: основной язык UI и помощника — азербайджанский (az-AZ), русский и смешанная RU/AZ речь сохраняются. Демонстрационные записи убираются из пользовательского пути. Владелец хочет использовать локальную память на своих данных; это разрешение на разработку и локальное использование, а не свидетельство технической приёмки защиты или согласие на автоматическую отправку архива. При автоматических и внешних API-проверках используются только синтетические данные. Последующее уточнение: пока проверяем только Gemini; платные услуги не подключаем.

## Диагноз и решение

В коде до этого изменения язык первого запуска — ru; у Live общая английская инструкция без приоритета AZ, словаря и запрета подмены турецким. Текстовый Gemini вообще не получает системной языковой инструкции. Системный TTS проверяет код возврата setLanguage, но не язык выбранного голоса. Live-транскрипт ограничен последними 4000 символами и не отделяет реплики. Эти дефекты кода подтверждены чтением; вклад каждого в услышанный дефект без одинаковых аудиозаписей пока не измерен.

Для диалога сохраняем Firebase AI Logic + App Check → Gemini 3.1 Live. AZ задаётся системной инструкцией, не неподдерживаемым параметром языка native audio. Настраиваем VAD для сохранения начала слова и естественных пауз; при инициализации микрофона используем Android VOICE_COMMUNICATION. Модель не получает инструменты или архив автоматически.

**Решение уточнено по реальным синтетическим пробам:** общий audio understanding через generateContent оказался медленным/ненадёжным и исключён из маршрута заметки. Специализированный `gemini-3.5-transcribe-live` работает через существующий Firebase Google AI WebSocket-прокси, но Firebase Android SDK 18.1.0 пока не предоставляет languageCodes/mode. Узкий протокольный адаптер сохраняет тот же Firebase endpoint, App Check и Android package/cert, без общего Gemini-секрета, обхода защиты или нового backend. Настройки: az-AZ/ru-RU, VERBATIM, один manual-VAD turn на заметку; принимается финальное inputTranscription, а не speculative interim. Поддержаны текстовые и бинарные JSON-фреймы; тайм-аут, отмена, ограничение аудио/текста/очереди, отсутствие request logging и автоматического fallback обязательны. Это preview-совместимость, не официальное обещание Firebase поддерживать модель; переход на SDK нужен после появления этих полей.

Распознавание иногда романизирует русские слова и пишет `değil`. Отдельный текстовый Gemini предлагает только пары «исходное слово → письменность». Код допускает фонетически совпадающую латиница→кириллица и `değil`→`deyil`; перевод, изменение чисел/отрицаний и перестановка слов отбрасываются. Пунктуация и прочие слова берутся из исходного STT. Неоднозначные имена остаются исходными. В UI предложение редактируется, исходное распознавание доступно для сверки/возврата; затем пользователь явно добавляет текст в черновик и сохраняет. Это обработанный текст после проверки, а не сохранённая аудиозапись или доказательство идеального STT.

Память: используем существующее шифрованное хранилище источников и версий, локальный поиск с учётом азербайджанского регистра и ссылки на точный источник. Отображаем только сохранённые записи. Голосовой текст переходит в редактируемый черновик после действия пользователя; ответ AI не становится личным фактом. Существующий непустой черновик нельзя молча заменить. Отсутствие совпадений не превращается в ответ о личной истории. Существующие язык/тема и данные сохраняются.

Источники: [Google Transcribe](https://ai.google.dev/gemini-api/docs/transcribe), [цены Google](https://ai.google.dev/gemini-api/docs/pricing), [Scribe](https://elevenlabs.io/docs/eleven-creative/playground/speech-to-text), [цены ElevenLabs](https://elevenlabs.io/pricing/api), [Groq STT](https://console.groq.com/docs/speech-to-text). Цены — сравнение по прямому запросу владельца, не разрешение расходов. Общие WER и рекламные проценты не являются оценкой азербайджанского.

Gemini Transcribe Live выбран для заметки как доступный в текущей защищённой интеграции и разрешённый владельцем вариант, с отдельной проверкой текста. Файловый Transcribe через Interactions API не подключён и не подменён generateContent. Scribe/Groq не вызываются. Честного победителя по точности AZ/RU без одинакового независимого аудиокорпуса для всех кандидатов пока нет; выбранный маршрут не объявляется самым точным провайдером.

Протокол и ограничения сверены с [Live Transcribe](https://ai.google.dev/gemini-api/docs/live-api/live-transcribe), [Android AudioTranscriptionConfig](https://firebase.google.com/docs/reference/android/com/google/firebase/ai/type/AudioTranscriptionConfig) и официальным source artifact `com.google.firebase:firebase-ai:18.1.0` из Google Maven. Внешние проверки используют синтетический TTS→STT roundtrip; он не отделяет ошибку синтеза от распознавания. Raw WER штрафует допустимую запись словесного числа цифрами, поэтому не равен семантической ошибке. Фактические результаты и непройденные критерии — ACT-0035.

Текстовая стадия — отдельные токены `gemini-3.1-flash-lite`: ориентир $0.25/1 млн входных текстовых токенов и $1.50/1 млн выходных по той же странице цен; это не включено в STT-цену за минуту. Для чисто кириллической записи стадия пропускается; используется конфигурация модели по умолчанию ([документация thinking](https://firebase.google.com/docs/ai-logic/thinking)), тайм-аут 15 с с возвратом исходного STT при отказе. Платёжные настройки не менялись. Фактические времена, ошибки и непройденная приёмка смешанных имён — [отчёт проверки](VOICE_EVAL_2026-10-31.md).

Для TTS не выбираем турецкий голос вместо отсутствующего азербайджанского. Gemini 3.x официально перечисляет AZ; голосовая инструкция усиливается. Eleven v3/v4 также перечисляют AZ, но остаются альтернативой без подключения. [Firebase: язык, голос и VAD](https://firebase.google.com/docs/ai-logic/live-api/configuration), [Live languages](https://ai.google.dev/gemini-api/docs/live-api/capabilities), [Eleven voices](https://elevenlabs.io/docs/overview/models).

## Приёмка

- Новый профиль открывается на AZ, сохранённый выбор RU/EN не затирается.
- Синтетические AZ, RU и смешанные фразы с ə/ı/İ/ğ/q/x, числами, отрицанием и самокоррекцией сохраняются без перевода и самовольного исправления фактов.
- Нет сетевого запроса до согласия; остановка/фон/отмена освобождают микрофон, поздние результаты не применяются.
- Нет автоматической записи ответа AI в память, подмены непустого черновика или выдуманных данных на главной/в памяти/финансах.
- Автоматические проверки покрывают язык, исходники, поиск, отказы/повторы и согласия. Качество произношения и WER/CER оцениваются отдельно по реальному аудио; до измерения улучшение не объявляется доказанным.

Текущий статус реализации и результатов — в дневнике и ACT-0035; эта запись задаёт решение до кода.
